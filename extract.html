Runs in your browser. Photos never leave your device.

Extract EXIF data to JSON, CSV or text

Pull the metadata out of one photo or hundreds. Save it as a spreadsheet, a JSON file or a text report, along with the embedded thumbnail and raw XMP.

Exports include every tag found in each photo.

    

  


  

    
What you get

    
CSV has one row per tag with the file name, group, tag and value columns, so many photos stack neatly in one spreadsheet. JSON keeps each photo’s metadata grouped. Text is a readable report for a single photo. You can also save the small preview image that many cameras embed in the file, and the raw XMP block.

    
Reads JPEG, PNG, WebP, TIFF, HEIC and AVIF. Includes EXIF, GPS, XMP, IPTC and colour profile details.

  


  

  


  

    
Questions

    

      
Are my photos uploaded?
No. Extraction runs entirely in this tab.

      
Why is the embedded thumbnail sometimes different from the photo?
The thumbnail is written when the photo is taken and edits often do not update it. That is why it can show the uncropped original.
